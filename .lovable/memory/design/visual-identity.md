## Palette
- Primary: `215 80% 50%` (tech blue)
- Accent: `190 55% 42%` (teal)
- Dark backgrounds: `220 25% 4-5%` (deep navy)
- No magenta. Purple only as very subtle gradient hints.
- Green WhatsApp: `142 70% 45%`

## Typography
- Font: Mona Sans (variable weight 200-900)
- Body: weight 400-420
- Labels/helpers: weight 420-450
- Headings: weight 300-400 (large sizes compensate)
- Navigation: weight 420
- Marquee: weight 440
- Avoid bold (>500) and ultra-thin (<380 for body)

## Components
- SpinBadge: reusable rotating SVG text badge
- PageBreadcrumb: breadcrumb wrapper for subpages
- ScrollBlur: dark navy gradient (not white)
- Cards: fixed 320px height, 160px image area

## Surfaces
- Glass: `bg-white/[0.04] backdrop-blur-20 border-white/[0.06]`
- Borders: `border-border/30` (subtle, not heavy)
- Dark sections: `section-dark` = `hsl(220 25% 5%)`
- Gradient mesh: navy tones, no purple
