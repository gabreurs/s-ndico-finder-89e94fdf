# Project Memory

## Core
Lovable Cloud (Supabase) stack with RLS: only 'approved' syndic profiles are visible publicly.
Design: Mona Sans font. Navy/blue tech palette (primary 215°). No magenta dominance.
Syndic workflow: Multi-step registration. States are pending, approved, rejected.
Cards: fixed 320px height, 160px image. SpinBadge + PageBreadcrumb components.

## Memories
- [Visual Identity](mem://design/visual-identity) — Navy/blue tech palette, Mona Sans typography, SpinBadge, glass surfaces
- [Search Filters](mem://features/sindico-filters) — Dynamic filtering by specialty, city, and region using CIDADES_REGIOES
- [Registration](mem://features/sindico-registration) — Multi-step registration flow and approval states
- [Image Upload](mem://features/image-upload) — Profile photo validation rules (5MB max, 300x300px min, JPG/PNG/WebP)
- [Syndic Profile](mem://features/sindico-profile) — Detailed profile with WhatsApp, YouTube, and related syndics carousel
